# web3min

Duolingo-style Web3 course in Indonesian. Pixel blobfish mascot, 20 rute, kuis + kisah.

## Jalanin lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:8080`.

Progress tersimpan di browser (`localStorage`, key `web3min-v2`).

## Isi

| Folder | Apa |
|---|---|
| `src/` | UI, rute, kurikulum, store |
| `public/worlds` | Background 20 rute |
| `public/mascot` | Sprite web3min |
| `public/proof` | Cuplikan X |
| `public/props` | Item pixel |
| `DESIGN.md` | Aturan visual |

```
npm run typecheck
npm run build
```
